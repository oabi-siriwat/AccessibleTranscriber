# Accessible Transcriber

ถอดเสียงพูดภาษาไทยเป็นข้อความ ได้ทั้งจากไมโครโฟน จากเสียงที่เล่นอยู่ในเครื่อง และจากไฟล์เสียงหรือวิดีโอ ทำงานในเครื่องทั้งหมด ไม่ต้องต่อเน็ต ไม่ต้องสมัครบัญชี

ทำมาสำหรับผู้ใช้โปรแกรมอ่านหน้าจอ หน้าต่างใช้ปุ่มมาตรฐานของ Windows ทุกปุ่มมีปุ่มลัด Ctrl เช่น Ctrl+O เปิดไฟล์ และ NVDA จะอ่านข้อความใหม่ให้ฟังทันทีที่ผู้พูดหยุด

English manual: [README.md](README.md)

## ดาวน์โหลด

ดาวน์โหลดเวอร์ชันล่าสุด: [AccessibleTranscriber.zip](https://github.com/oabi-siriwat/AccessibleTranscriber/releases/latest/download/AccessibleTranscriber.zip)

ลิงก์นี้ได้เวอร์ชันใหม่ล่าสุดเสมอ แตกไฟล์ zip จะได้โฟลเดอร์ AccessibleTranscriber ที่มี `AccessibleTranscriber.exe` กับคู่มือภาษาอังกฤษและภาษาไทย (`AccessibleTranscriber_README.txt`, `AccessibleTranscriber_README_TH.txt`) เปิด `AccessibleTranscriber.exe` จากโฟลเดอร์นั้น ไม่ใช่เปิดจากใน zip โปรแกรมเป็นไฟล์เดียว ขนาดประมาณ 200 MB เพราะมีโมเดลถอดเสียงอยู่ข้างใน ไม่ต้องติดตั้ง

ไฟล์นี้ไม่ได้เซ็นรับรอง Windows SmartScreen อาจเตือนว่าไม่รู้จักผู้เผยแพร่ ให้เลือก ข้อมูลเพิ่มเติม (More info) แล้วเลือก เรียกใช้ต่อไป (Run anyway)

## สิ่งที่ต้องมี

- Windows 10 หรือ Windows 11 แบบ 64 บิต
- ไมโครโฟน หรือเสียงที่เล่นในเครื่อง หรือไฟล์เสียงหรือวิดีโอ
- ไม่จำเป็นต้องมี NVDA แต่ถ้าเปิด NVDA อยู่ โปรแกรมจะพูดผ่าน NVDA

## วิธีใช้

1. เลือกแหล่งเสียง (Ctrl+I): ไมโครโฟน หรือเสียงในเครื่อง
2. กด Ctrl+T เริ่มฟัง แล้วพูด ข้อความจะขึ้นในช่อง Transcript
3. กด Ctrl+T อีกครั้งเพื่อหยุด แล้วกด Ctrl+S บันทึกข้อความเป็นไฟล์

Ctrl+O เปิดไฟล์เสียงหรือวิดีโอมาถอด ถอดเสร็จแล้วข้อความจะบันทึกเป็นไฟล์ .txt ชื่อเดียวกับไฟล์เสียง ในโฟลเดอร์เดียวกันให้เอง (ไม่เขียนทับไฟล์ที่มีอยู่) ระหว่างถอดไฟล์ หน้าต่างจะเหลือแค่ช่องสถานะ บอกชื่อไฟล์ % และเวลาที่เหลือ ใช้ได้แค่ 3 ปุ่ม: Space ฟังความคืบหน้า, F5 ฟังสถานะ, Escape หยุด (ถามก่อน) Ctrl+คอมม่า เปิดหน้าตั้งค่า: ภาษาเมนู (ไทยหรือ English), อ่านข้อความใหม่ให้ฟัง, ใส่เวลาหน้าแต่ละบรรทัด, แปลงคำตัวเลขเป็นเลขอารบิก, ตัดคำลังเล เช่น เอ่อ อ่า อืม, รายการแก้คำ และหยุดพูดนานเท่าไรจึงเว้นวรรคหรือขึ้นบรรทัดใหม่

รายการแก้คำ (ปุ่ม แก้รายการคำ ในหน้าตั้งค่า) ใช้แก้คำที่โปรแกรมมักถอดผิด เขียนบรรทัดละคำแบบ คำที่ถอดผิด=คำที่ถูก ในรายการมีคำอังกฤษที่ใช้บ่อยซึ่งโมเดลเขียนเป็นตัวไทยใส่ไว้ให้แล้ว เช่น ฟิตแบค=feedback คำเหล่านี้จึงออกมาเป็นภาษาอังกฤษ ถ้าไม่อยากให้คำไหนเปลี่ยน ใส่ # หน้าบรรทัดนั้น Ctrl+H เปิดวิธีใช้แบบเต็มในโปรแกรม

## อัปเดต

ทุกครั้งที่เปิดโปรแกรม โปรแกรมจะตรวจหาเวอร์ชันใหม่ให้เอง ถ้ามีจะถามก่อน แล้วดาวน์โหลด ตรวจไฟล์ และเปิดโปรแกรมใหม่ให้ ถ้าไม่มีจะไม่พูดอะไร ระหว่างดาวน์โหลดมีเสียง beep ทุก 1% บอก % ทุก 10 วินาที หน้าต่างจะเหลือแค่ช่องสถานะ กด Space ฟัง % กับเวลาที่เหลือ, F5 ฟังสถานะ, Escape หยุดดาวน์โหลด (ถามก่อน) ในหน้าตั้งค่า (Ctrl+คอมม่า) ก็มีปุ่ม ตรวจหาอัปเดต
